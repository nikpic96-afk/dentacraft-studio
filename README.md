# DentaCraft Studio — Сайты и цифровые экосистемы для стоматологий

Современный интерактивный веб-сайт специализированного диджитал-агентства **DentaCraft Studio** с интегрированным **демо-сайтом реальной стоматологической клиники** («NovaDent Clinic»).

---

## 🚀 Быстрый старт

Проект уже запущен на локальном сервере разработки:
👉 **[http://localhost:5173/](http://localhost:5173/)**

### Команды в терминале:
```bash
# Запуск сервера разработки
npm run dev

# Сборка готового production-сайта
npm run build

# Предпросмотр собранного проекта
npm run preview
```

## ⚙️ Как легко настроить контакты и цены под себя

Все ключевые данные собраны в одном конфигурационном файле:
📂 [`src/data/siteConfig.js`](file:///C:/Users/admin/.gemini/antigravity/scratch/dentacraft-studio/src/data/siteConfig.js)

Вы можете изменить:
- **Телефон, WhatsApp, Telegram, Email** агентства

- **Стоимость модулей в онлайн-калькуляторе**
- **Услуги и врачей в демо-клинике** NovaDent

## 🌟 Что реализовано в проекте:

1. **Главный сайт агентства DentaCraft Studio:**
   - **Hero-блок** с мощным медицинским оффером и интерактивным превью (переключение вкладок: онлайн-запись, До/После, МИС-синхронизация).
   - **Шоукейс услуг:** разработка под ключ, онлайн-запись 24/7, интеграция с МИС (IDENT, Инфодент, 1С), слайдеры «До/После», юридическое соответствие Минздраву и ФЗ-152, Mobile-First.
   - **Интерактивный калькулятор стоимости:** клиент выбирает масштаб клиники (1 кабинет / 2-6 кресел / сеть) и модули, получая динамический расчет сметы, сроков и прогноз прироста пациентов.
   - **Сравнение подходов:** «Типичная веб-студия» vs «Специализированная DentaCraft Studio».
   - **Тарифная сетка:** прозрачные пакеты с перечнем всех включенных опций.
   - **Этапы работы:** 5 понятных шагов без лишней нагрузки на врачей.
   - **База знаний (FAQ):** интерактивный аккордеон с ответами на главные вопросы руководителей клиник.
   - **Модальное окно заявки:** с анимацией конфетти и быстрыми ссылками в мессенджеры.

2. **Интерактивный Демо-сайт стоматологии («NovaDent Clinic»):**
   - Переключение в 1 клик через верхний баннер и плавающую кнопку.
   - Каталог услуг с фильтрацией по направлениям (Имплантация, Ортодонтия, Виниры, Терапия, Гигиена, Детство) и поиском.
   - **Интерактивный слайдер «До и После»:** можно двигать бегунок мышкой или пальцем и видеть результат реставрации улыбки.
   - Каталог врачей с опытом, специализацией и кнопками записи.
   - **Интерактивный мастер онлайн-записи:** выбор услуги, врача, даты, свободного времени и моментальное подтверждение.
